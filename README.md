# 🎓 Previsão de Vendas de Cursos

> Previsão de matrículas e vendas de cursos para edtechs e instituições. Antecipa demanda por curso e período, otimiza marketing e dimensiona turmas e infraestrutura.

## 📊 Resultados-chave (KPIs)

Time Series · ML · Demand Forecasting

## ✨ O que faz

- Dimensionamento de turmas

## 🗄️ Fonte de dados real

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Matrículas + sazonalidade + marketing
2. **Processamento com IA** — Time Series · ML · Demand Forecasting
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
